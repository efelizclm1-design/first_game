# Pixel Panic

Juego de acción 2D en pixel art oscuro, creado para Godot 4.

**20 niveles · 5 zonas · 5 jefes · 3 vidas · teclado y controles táctiles**

Importa `project.godot` en Godot **4.6.3 estándar** y pulsa **F5**.

- [Guía completa en español](LEEME.md)
- [Pruebas y límites de la validación](VALIDACION.md)

Todo el arte y el audio está incluido. El proyecto no necesita servicios externos.

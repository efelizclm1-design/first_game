# Pixel Panic

Juego de acción 2D en pixel art para Godot 4. **Versión 0.2: arenas y combate renovados.**

**20 escenarios · 5 mundos · 5 jefes · 3 vidas · teclado y controles táctiles**

Otoño, hielo, ciudad, paraíso e infierno: cada nivel tiene su propio paisaje e
inhabitantes. Esquiva los ataques anunciados, dispara hacia donde miras y supera
una dificultad que aumenta gradualmente. El primer nivel siempre ofrece una guía
y seis ejercicios seguros; puedes omitirlos.

Importa `project.godot` en Godot **4.6.3 estándar** y pulsa **F5**.

- [Guía completa en español](LEEME.md)
- [Pruebas y límites de la validación](VALIDACION.md)
